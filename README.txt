ISAAC INFINITY — FUSION V2 (Android universel)

Fusionne les fonctions locales de la V1 (Isaac Mirror, Isaac Creator, Isaac Next, Mes projets, sauvegarde/export local) avec un nouvel onglet « Isaac IA en ligne ».

COMPATIBILITÉ
L’interface est une application web responsive destinée aux navigateurs Android récents, dont Infinix, Tecno, Samsung, Xiaomi et autres. L’APK final dépend du convertisseur et de la version Android ; compatibilité garantie impossible sans test sur chaque appareil.

CONVERSION EN APK
1. Extrais ce ZIP si le convertisseur ne prend pas les archives ZIP.
2. Sélectionne ISAAC_INFINITY_FUSION/index.html dans le convertisseur HTML → APK.
3. Nom : ISAAC INFINITY ; package suggéré : com.isaac.infinity.
4. Génère l’APK et teste-le.

IA EN LIGNE
Le nouvel onglet IA permet de saisir l’adresse d’un serveur et d’envoyer les questions à /cerveau. Le dossier server contient un serveur Flask de base. Pour les réponses avancées, héberge-le sur Internet et configure les variables d’environnement AI_API_URL, AI_API_KEY et AI_MODEL avec un fournisseur compatible. Sans serveur hébergé/configuré, l’IA complète ne fonctionnera pas. Ne mets jamais la clé secrète dans le HTML ou l’APK.

WHATSAPP
Le bouton prépare un partage de réponse. Il n’envoie pas automatiquement des messages à un groupe WhatsApp.

Ce ZIP ne corrige pas un installateur Android qui plante sur le téléphone.
